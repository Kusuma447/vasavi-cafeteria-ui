# 🍽️ Vasavi Cafeteria

A canteen management web app built for Sri Vasavi Engineering College.

**Live Demo:** [vasavi-cafeteria-ui-git-main-kusumas-projects-b4cc15a8.vercel.app](https://vasavi-cafeteria-ui-git-main-kusumas-projects-b4cc15a8.vercel.app)



## 💡 The Idea

During my first year, after a sports session, my friends and I walked all the way to the canteen — only to find it closed.

That moment made me think — why don't we know this before coming here?

I couldn't build it then. Second year, I learned and built it from scratch.



## ✨ Features

- 5 menu category pages — Biryani, Tiffins, Chat Masala, Bakery, Cool Drinks
- Search functionality on every page
- Add to cart across multiple pages
- Live bill total with quantity tracking
- Food availability status (green/red indicator)
- Animated cart drawer
- Sign up page with validation
- Responsive design



## 🛠️ Built With

- HTML
- CSS
- JavaScript (Vanilla)
- LocalStorage for cart persistence
